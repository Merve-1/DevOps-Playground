# Cloud DevOps Playground

A hands-on learning repository for exploring cloud technologies, DevOps practices, and application deployment across different technology stacks.

## 📌 Overview

Cloud DevOps Playground is a collection of projects designed to practice software development, containerization, microservices, and DevOps workflows. Each branch focuses on a different implementation or technology.

## 🌿 Project Branches

| Branch | Description |
|---|---|
| `main` | Main project overview and documentation |
| `AWS-E-Commerce-Application` | AWS-based e-commerce application |
| `Docker-for-.Net` | Docker and .NET application practice |

## 🛠️ Technologies

Technologies explored in this repository may include:

- **Cloud:** Amazon Web Services (AWS)
- **Containers:** Docker
- **Backend:** .NET
- **Architecture:** Microservices
- **DevOps:** CI/CD, deployment automation, and infrastructure management

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/Merve-1/Cloud-DevOps-Playground
cd Cloud-DevOps-Playground
```

List available branches:

```bash
git branch -a
```

Switch to a project branch:

```bash
git switch AWS-E-Commerce-Application
```

Follow the README and setup instructions in the selected branch to run that project.

## 🎯 Goals

- Practice cloud application deployment.
- Learn containerization with Docker.
- Explore microservices architecture.
- Improve CI/CD and automation skills.
- Build practical experience with cloud and DevOps tools.
